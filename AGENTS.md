# AGENTS.md

Шпаргалка для агентов, работающих с этим репо.

## Окружение

- Go ≥ 1.26, только stdlib + `pelletier/go-toml/v2`. **CGO запрещён** —
  нужна чистая кросс-компиляция из macOS (`GOOS=linux GOARCH=amd64|arm64`).
- Целевая машина: linux + niri (Wayland). На ней проверять всё, что
  касается клавиатуры/буфера/IPC.
- Проверки перед коммитом: `go vet ./... && go test ./...`

## Структура

- `layout/` — позиционная конвертация QWERTY↔ЙЦУКЕН (таблица из wksw,
  проверена на реальной машине; не «улучшать» на глаз).
- `dict/` — частотные словари (`go:embed`, `dict_data/{en,ru}_freq.txt`,
  формат `слово частота`) + пользовательские словари.
- `analyze/` — детект слова не в той раскладке: словарный скоринг,
  консервативный порог (фикс только при явной уверенности).
- `config/` — TOML-конфиг (`~/.config/lapsus/config.toml`).
- `cmd/lapsus/` — CLI: `check`, `convert`; `fix` (M1), `daemon` (M2).

## Принятые решения (не откатывать без обсуждения)

- Никакого libei/EIS — niri не даёт EIS-сервер. Инъекция — внешний `wtype`,
  чтение буферов — `wl-paste`/`wl-copy`, композитор — `niri msg` (NIRI_SOCKET).
- Переключение раскладки — `niri msg action switch-layout`, всегда ПОСЛЕ
  инъекции текста (niri#3568: vkbd-события сбрасывают группу).
- Порядок работ — TODO.md (M0→M3). История и архитектура — README.md.
- Старые репо: `../wksw` (Rust, прототип пайплайна), `../oshitkeyb`
  (Go, предыдущая инкарнация) — только чтение, не развивать.
