## Известные грабли

- **niri#3568** — события виртуальной клавиатуры сбрасывают xkb group:
  порядок всегда «inject → switch-layout».
- `niri msg action switch-layout` принимает только `next|prev|<index>`
  (имя раскладки — нет); текущий индекс — из `niri msg --json
  keyboard-layouts` (нет в старых niri). С `track-layout "window"`
  свитч действует на раскладку сфокусированного окна.
- primary selection обновляют не все приложения (многие терминалы — нет),
  отсюда отдельный терминал-режим.
- `wtype` шлёт keysyms — вставляет кириллицу независимо от активной
  раскладки (это наш козырь, не баг).
- частоты en/ru из одного корпуса (OpenSubtitles) — сопоставимы между
  собой; если менять источник для одного языка, порог `×2` в analyze
  надо калибровать заново.
