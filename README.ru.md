# lapsus

[English](README.md) | [Русский](README.ru.md)

Фиксер раскладки RU↔EN для Linux/Wayland, собран под [niri](https://github.com/niri-wm/niri) — в духе Punto Switcher. Набрал `ghbdtn` вместо `привет`? lapsus перевернёт текст обратно: автоматически на границе слова или по хоткею. Название — от лат. *lapsus linguae*, «оговорка».

## Возможности

- **Демон авто-фикса** — читает нажатия напрямую из `/dev/input` (без grab и root), держит текущее слово в буфере и чинит его на границе слова — но только когда словари уверены: перевёрнутое прочтение должно быть словарным словом, а оригинал — нет.
- **Хоткей-тумблер** — одно нажатие переворачивает слово у каретки в другую раскладку безусловно (явное нажатие в словаре не нуждается), и раскладка следует за словом. Второй хоткей делает то же с выделенным текстом, фразу — пословно.
- **Память языка по приложениям** — помнит, на каком языке ты печатаешь в каждом приложении, и возвращает этот язык при фокусе окна. Новые окна знакомых приложений сразу «на своём языке», а для незнакомых — настраиваемый дефолт (`daemon.default_layout`: выкл / en / ru).
- **Иконка в трее** — флаг активной раскладки, приглушён на паузе; меню с тумблерами (авто-фикс / звук / нотификации) с сохранением в конфиг.
- **Фидбек** — системная нотификация и звук при каждом перевороте (опционально).
- **systemd user unit** в комплекте (`deploy/lapsus.service`).

## Требования

- Linux, Wayland; интеграция с композитором сейчас — [niri](https://github.com/niri-wm/niri) (переключение раскладки и фокус окна через `niri msg`)
- Go ≥ 1.26 (для сборки; CGO не используется)
- [wtype](https://github.com/atx/wtype), [wl-clipboard](https://github.com/bugaevc/wl-clipboard)
- `libnotify-bin` для нотификаций (опционально)
- членство в группе `input` для демона (читает `/dev/input` без grab, без root)

## Сборка и установка

```sh
go build -o ~/.local/bin/lapsus ./cmd/lapsus
lapsus check                     # самопроверка: конфиг, словари, анализатор
lapsus convert "Ghbdtn? vbh!"    # → Привет, мир!
```

Кросс-компиляция чистая (без CGO):

```sh
GOOS=linux GOARCH=arm64 go build -o dist/lapsus-linux-arm64 ./cmd/lapsus
```

Постоянный запуск — systemd user unit:

```sh
cp deploy/lapsus.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now lapsus
journalctl --user -u lapsus -f
```

## Хоткеи

Бинд `lapsus fix` в `~/.config/niri/config.kdl`:

```kdl
binds {
    // На этом ThinkPad голый Fn приходит как XF86WakeUp.
    // Правый Alt превращён в Compose-клавишу (compose:ralt), потому что
    // клавишу-модификатор соло в niri забиндить нельзя.
    XF86WakeUp      { spawn "lapsus" "fix"; }              // слово у каретки
    Ctrl+XF86WakeUp { spawn "lapsus" "fix" "--selection"; } // выделенное
}
```

- **`lapsus fix`** — переворачивает слово слева от каретки, затем переключает раскладку на язык исправленного слова.
- **`lapsus fix --selection`** — переворачивает выделенное (мышь или Shift+стрелки); фраза — пословно с сохранением пробелов.
- Отладка: `lapsus fix -v` (пошаговый лог), `lapsus fix -n` (dry run).

## Демон

Демон читает клавиатуру напрямую через `/dev/input` (без grab, без root), сам набирает текущее слово из потока клавиш и на границе слова чинит его:

```
клавиатура (evdev, группа input) ──► буфер слова ──► граница:
                                       ▲             пробел / , . ; / ? ! :
                                       │
niri event-stream: активная раскладка ─┘                │
и фокус окна                                     analyze (словари)
                                                        │ уверен?
                                                        ▼
                                 BackSpace ×N + ввод исправления
                                                        ▼
                                 niri msg action switch-layout (последним)
```

- Слово завершается **любым печатным разделителем** — пробел, пунктуация, кавычки, скобки, дефис: «слово)» чинится так же, как «слово ». Enter, Tab, стрелки и Ctrl/Alt-комбо сбрасывают буфер без фикса (текст мог уже «уехать» — выполненная команда, автодополнение, съехавшая каретка).
- Замена одинакова везде — в GUI и в терминалах: BackSpace × длина слова, затем ввод исправления. Выделения и буфер обмена не нужны.
- Устройства опрашиваются раз в 3 с (hotplug); раскладка и фокус трекаются через `niri msg --json event-stream`.

### Трей

Иконка рисуется кодом (без ассетов): флаг активной раскладки, приглушён на паузе. Меню открывается и левым, и правым кликом:

- **Автопереключение** — пауза/возобновление демона (как SIGUSR1);
- **Звук** и **Нотификации** — тумблеры фидбека;
- **Выход** — остановить демона.

Тумблеры применяются мгновенно и сохраняются в конфиг.

### Пауза

```kdl
Mod+Shift+P { spawn "pkill" "-USR1" "lapsus"; }   // тумблер авто-фикса
```

## Конфигурация

`~/.config/lapsus/config.toml` (все ключи опциональны, дефолты валидны):

```toml
[fix]
switch_layout = true     # переключать раскладку на язык исправленного слова
pause_ms      = 50       # пауза после синтетических нажатий (wtype)

[feedback]
notify = true            # системная нотификация при перевороте
                       # (нужен: sudo apt install libnotify-bin)
sound  = "bell"        # "bell" (freedesktop), путь к файлу или ""

[daemon]
tray                   = true  # иконка в трее: флаг раскладки + тумблеры
remember_window_layout = true  # помнить язык каждого приложения
default_layout         = ""    # язык для окон невыученных приложений:
                               # "", "en" или "ru" ("" = не трогать)
exclude_app_ids        = []    # app_id, где авто-фикс выключен (VM, игры)
switch_layout      = false # демон не трогает раскладку вовсе: он чинит
                           # слово, а решать, где продолжать, — тебе
boundary_pause_ms  = 0    # паузная граница выключена: слово завершается
                          # только печатным разделителем (0 = off,
                          # включать в [50, 5000] на свой риск обрывков)
min_word_len       = 3    # короче — демон не трогает (обрывки и одиночные
                          # буквы; хоткей чинит любые слова)

[hotkey]
terminals = ["foot", "kitty", "Alacritty", "wezterm", "ghostty", "st"]

[capture]
method = "clipboard"     # clipboard (primary selection) | cut (Ctrl+X-фолбэк)

[autodetect]
mode = "both"            # hotkey | continuous | both

[dictionary]
user_dir = "~/.config/lapsus/dicts"   # en_freq.txt / ru_freq.txt
```

Пользовательские словари: `en_freq.txt` / `ru_freq.txt`, формат `слово частота` (по слову в строке), переопределяют встроенные частоты — туда можно добавлять свои термины, никнеймы, названия проектов.

## Словари

`dict/dict_data/{en,ru}_freq.txt` — top-20 000 слов, [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (corpus: OpenSubtitles 2018). Обновить:

```sh
curl -fsSL https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/en/en_50k.txt | head -n 20000 > dict/dict_data/en_freq.txt
curl -fsSL https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/ru/ru_50k.txt | head -n 20000 > dict/dict_data/ru_freq.txt
```

## Как работает конвертация

Таблица в `layout/layout.go` позиционно-верная: символ заменяется на символ с той же физической клавиши (с учётом Shift) другой раскладки. Следствия:

- `?` → `,` (Shift+/ на ЙЦУКЕН даёт запятую) и обратно; `@ # $ ^ &` → `" № ; : ?`;
- `` ` `` ↔ `ё`, `~` ↔ `Ё`, `<` ↔ `Б`, `>` ↔ `Ю`;
- цифры и непомапленные символы проходят как есть.

Пунктуация по краям слова при фиксе **переворачивается вместе со словом** — знак был набран теми же физическими клавишами в той же неверной раскладке: `руддщ,` → `hello?` (Shift+/ в ЙЦУКЕН даёт «,», а пользователь имел в виду «?»), `ghbdtn,` → `приветб`. Совпадающие в обеих раскладках знаки (скобки, пробел, `!`) проходят без изменений. Демон делает то же с завершающим слово разделителем.

## Известные ограничения

- Зажатые клавиши (автоповтор) инвалидируют буфер слова демона — такое слово пропускается, порчи нет.
- Последнее слово перед Enter не чинится: Enter сбрасывает буфер, чтобы не трогать уже выполненную команду.
- Быстрая печать прямо в момент инъекции может перемешаться с ней (без grab перехватить нечего).
- Перемещение каретки мышью демон не видит — набранное до клика слово не чинится.
